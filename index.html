Ableton Tools

Two small, read-only friends for Ableton Live 12 — built side by side.

Ableton Caddy

A local companion that reads your open set through the Live MCP bridge and suggests processing chains one channel at a time — each with a reason to try it and something specific to listen for. It never changes your set.

Try the live demo (no install) Source macOS app + releases

With Live open: install AbletonMCP via the link below, then start the app — the demo above runs entirely in your browser and shows the real UI against a built-in example set.

Ableton MCP Link

A desktop installer for the Ableton Live MCP bridge: it activates the AbletonMCP Control Surface in Live and configures your MCP clients (VS Code, Claude, Hermes…) to talk to it. Caddy runs on top of exactly this bridge, same pinned version.
